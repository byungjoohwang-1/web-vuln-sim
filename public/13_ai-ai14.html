🕵️ 멤버십 추론 (프라이버시)

AI/LLM 보안 · 적대적 ML

위험도: 중

📋 취약점 개요

특정 데이터가 학습에 쓰였는지를 모델 응답 신뢰도 차이로 추론하는 공격입니다. 개인정보가 학습되었는지 확인(법적 문제)되어 침해로 이어집니다.

🖥️ 상태 비교 시뮬레이션

ai$ (취약)
# 특정인 데이터로 질의 반복 attacker$ "홍길동 정보" 신뢰도 비교 쿼리 >> 해당 기록 응답이 유의하게 높음 → 학습 포함 추정 — 개인정보 침해

🔧 조치 방법

  1. 차등 프라이버시(DP) 기법을 학습에 적용합니다.
  2. 과적합을 줄이는 정규화와 조기 종료를 사용합니다.
  3. 민감 개인정보는 가명·익명 처리 후 학습합니다.

✅ 점검 체크리스트

  • 개인정보 익명처리 후 학습됨
  • 응답 차이 최소화(DP/정규화) 적용
