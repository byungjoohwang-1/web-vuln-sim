🛜 차량 Wi-Fi 접근점 오구성 (내부 서비스 노출)

자동차 보안 · 무선·텔레매틱스

위험도: 중
💡 쉽게 말하면
차량 Wi-Fi 오구성은 카페 손님용 와이파이에서 주방 발주 시스템이 그대로 보이는 상황입니다. 편의를 위해 연 문이 내부 업무망까지 이어져 있습니다.

🎯 직접 해보기 — 공격을 실행해 보세요

아래에서 시스템 상태를 취약 또는 안전(조치 적용)으로 바꾼 뒤 공격 실행을 눌러, 같은 공격이 어떻게 다르게 끝나는지 직접 확인하세요.

현재: 취약한 설정 — 공격이 통할까요?
# 승객용 Wi-Fi에 붙어 내부 서비스를 찾아본다 # [공격 실행] 버튼을 누르면 시작합니다.

📋 설정 비교 (왜 막혔나?)

✗ 취약한 설정
# 승객용 Wi-Fi 접속 후 내부 스캔 attacker$ nmap 192.168.8.0/24 >> 텔넷 23, 진단 13400, 관리 웹 8080 응답 → 공용 비밀번호로 전 차량 동일 접속
✓ 안전한 설정
# 게스트망 분리 + 차량별 자격증명 ivi$ guest vlan only ; per-vehicle psk ; mgmt not routed >> 게스트 대역에서 내부 서비스 도달 불가 → 차량별 고유 자격증명 사용

🔧 조치 방법

  1. 게스트 Wi-Fi를 별도 세그먼트로 분리하고 내부 서비스로의 라우팅을 차단합니다.
  2. 차량별 고유 자격증명을 사용하고 공용·기본 비밀번호를 제거합니다.
  3. 최신 무선 암호화를 강제하고 클라이언트 간 격리를 활성화합니다.

✅ 점검 체크리스트

  • 게스트망 분리 확인
  • 차량별 고유 자격증명
  • 내부 서비스 미노출
