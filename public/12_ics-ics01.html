ICS-01

🔑 PLC/HMI 기본 계정·비밀번호 사용

제어시스템(ICS/SCADA) · 계정/접근

위험도: 상
💡 쉽게 말하면
PLC/HMI의 기본 비밀번호는 출고 때 붙은 표준 자물쇠입니다. 누구나 매뉴얼만 보면 여는 똑같은 열쇠를 가지고 있죠. 비밀번호를 바꾸는 건 내 자물쇠로 교체하는 것입니다.

🎯 직접 해보기 — 공격을 실행해 보세요

아래에서 시스템 상태를 취약 또는 안전(조치 적용)으로 바꾼 뒤 공격 실행을 눌러, 같은 공격이 어떻게 다르게 끝나는지 직접 확인하세요.

현재: 취약한 설정 — 공격이 통할까요?
# 제조사 매뉴얼의 기본 계정으로 HMI에 로그인한다 # [공격 실행] 버튼을 누르면 시작합니다.

📋 설정 비교 (왜 막혔나?)

✗ 취약한 설정
# HMI 로그인 계정 ics$ show users admin / admin (제조사 기본값) → 매뉴얼만 보면 누구나 로그인
✓ 안전한 설정
# 기본 계정 변경/삭제 ics$ passwd admin ; disable guest 강한 비밀번호 + 불필요 계정 삭제 → 기본값 로그인 차단

🔧 조치 방법

  1. 모든 기본 계정의 비밀번호를 즉시 변경하고 불필요한 계정은 삭제합니다.
  2. 계정별 권한을 분리하고(운영/조회) 공용 계정 사용을 금지합니다.
  3. 가능한 장비는 계정 잠금·접근 로그를 활성화합니다.

✅ 점검 체크리스트

  • 제조사 기본 계정이 변경/삭제됨
  • 계정별 권한이 분리됨
  • 공용 계정을 사용하지 않음
