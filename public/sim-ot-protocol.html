🏭 OT 산업 프로토콜 실습OT Industrial Protocol Lab Modbus · DNP3 · OPC UA

모의 정수장 제어망 HANARO 정수장에 산업 프로토콜로 직접 명령을 보내 인증 부재·평문 통신·마스터 스푸핑·PLC 로직 변조 등을 시험합니다. 각 위험은 명령 실행 → 취약/양호 판정 → 방어 적용 → 재점검 순서로, 방어(세그멘테이션·인증·보안정책)를 켜면 같은 명령이 이번엔 막히는지 확인합니다. Send industrial-protocol commands to a mock water-treatment control network (HANARO): missing authentication, cleartext traffic, master spoofing, PLC logic tampering, and more. Each risk runs command → verdict → apply defense → re-check — watch the same command get blocked once the defense (segmentation / authentication / security policy) is on.

교육용 시뮬레이션입니다. HANARO 정수장은 전부 이 페이지 안의 mock 이며 실제 PLC 접속이나 프로토콜 전송은 전혀 없습니다. 위험 분류는 공개 기준(IEC 62443, NIST SP 800-82, KISA 제어시스템 가이드)을 개념적으로 재구성했습니다. Educational simulation. HANARO is a fully in-page mock — no real PLC access or protocol traffic. Risk taxonomy follows public guidance (IEC 62443, NIST SP 800-82).
⚠️ 제어시스템은 사람의 안전과 직결됩니다. IT 보안 점검 기법(포트 스캔·퍼징·취약점 스캐너)을 운영 중인 OT 망에 그대로 쓰면 PLC 가 정지하거나 공정이 멈출 수 있습니다. 실제 점검은 반드시 사전 승인·정지 계획·오프라인 테스트베드에서 수행합니다. 이 실습은 그 위험을 안전하게 이해하기 위한 것입니다. Control systems are safety-critical. Applying IT testing techniques (port scans, fuzzing, vulnerability scanners) to a live OT network can halt PLCs and stop the process. Real assessments require prior approval, an outage plan, and an offline testbed. This lab exists so you can understand that risk safely.
