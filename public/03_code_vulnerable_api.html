☕ Java 코드 에디터 취약한 코드
Util.java 💡 예측가능 Random/문자열 exec 대신 SecureRandom과 ProcessBuilder를 쓰세요. 
// [취약] 보안에 부적합한 API: 예측가능 Random, 문자열 exec(셸 인젝션)
Random rnd = new Random();
String token = Long.toHexString(rnd.nextLong());
Runtime.getRuntime().exec("sh -c 'backup " + name + "'");
💡 수정 가이드 (KISA 기준)
1. 안전한 API

SecureRandom + ProcessBuilder.

SecureRandom rnd = new SecureRandom(); String token = Long.toHexString(rnd.nextLong()); new ProcessBuilder("backup", name).start(); // 인자 분리(셸 미경유)

🐍 Python 코드 에디터 취약한 코드
util.py 💡 random/os.system 대신 secrets와 subprocess.run(리스트)을 쓰세요. 
import random, os
# [취약] 보안 부적합 API: random(예측가능), os.system(셸 인젝션)
token = str(random.random())
os.system("backup " + name)
💡 수정 가이드 (KISA 기준)
1. 안전한 API

secrets + subprocess.run 리스트.

import secrets, subprocess token = secrets.token_hex(16) subprocess.run(["backup", name], check=True) # 인자 리스트(셸 미경유)
