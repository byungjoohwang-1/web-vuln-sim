🎧 리스너 비밀번호 설정

데이터베이스 보안

위험도: 상

📋 취약점 개요

리스너에 비밀번호가 없으면 원격에서 리스너를 정지(STOP)하거나 설정을 변경하는 서비스 거부·정보 노출이 가능합니다. 비밀번호를 설정해야 합니다.

🖥️ 상태 비교 시뮬레이션

root@server:~# (취약)
-- 리스너 상태 # lsnrctl status Security ON: Local OS Authentication 없음 → 원격에서 리스너 제어 가능 (취약)

🔧 조치 방법

  1. listener.ora에 리스너 비밀번호를 설정합니다.
  2. 최신 버전은 로컬 OS 인증을 사용하고 원격 관리(ADMIN_RESTRICTIONS=ON)를 제한합니다.

✅ 점검 체크리스트

  • 리스너 비밀번호/관리 제한이 설정됨
  • 원격 리스너 제어가 차단됨
