🔁 자동 로그온 비활성화

Windows 서버 · 보안 관리

위험도: 상
💡 쉽게 말하면
자동 로그온은 편하지만, 비밀번호를 현관 매트 밑에 적어 두는 것과 같습니다. 레지스트리에 평문으로 적힌 암호를 누구든 읽을 수 있고, 부팅만 하면 바로 로그인되죠.

🎯 직접 해보기 — 공격을 실행해 보세요

아래에서 시스템 상태를 취약 또는 안전(조치 적용)으로 바꾼 뒤 공격 실행을 눌러, 같은 공격이 어떻게 다르게 끝나는지 직접 확인하세요.

현재: 취약한 설정 — 공격이 통할까요?
# 공격자가 레지스트리에서 평문 암호를 읽어낸다 # [공격 실행] 버튼을 누르면 시작합니다.

📋 설정 비교 (왜 막혔나?)

✗ 취약한 설정
# 자동 로그온 확인 PS> reg query "...\Winlogon" /v AutoAdminLogon AutoAdminLogon 1 / DefaultPassword 평문 → 평문 암호 저장+자동 로그인 (취약)
✓ 안전한 설정
# 비활성화 + 평문 제거 PS> AutoAdminLogon=0; DefaultPassword 삭제 AutoAdminLogon 0 → 자동 로그온 해제 (양호)

🔧 조치 방법

  1. AutoAdminLogon을 0으로 설정하고 DefaultPassword 값을 삭제합니다.

✅ 점검 체크리스트

  • 자동 로그온이 비활성화됨
  • 레지스트리 평문 암호가 제거됨
