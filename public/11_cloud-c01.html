🔑 루트 계정 MFA 미적용

클라우드/컨테이너 · 계정/권한

위험도: 상
💡 쉽게 말하면
루트 계정은 건물 마스터키입니다. 비밀번호 하나만 알면 모든 문을 엽니다. MFA는 마스터키에 두 번째 잠금을 다는 것이라, 비밀번호가 새도 두 번째 잠금 없이는 못 들어옵니다.

🎯 직접 해보기 — 공격을 실행해 보세요

아래에서 시스템 상태를 취약 또는 안전(조치 적용)으로 바꾼 뒤 공격 실행을 눌러, 같은 공격이 어떻게 다르게 끝나는지 직접 확인하세요.

현재: 취약한 설정 — 공격이 통할까요?
# 유출된 비밀번호로 루트 콘솔에 로그인한다 # [공격 실행] 버튼을 누르면 시작합니다.

📋 설정 비교 (왜 막혔나?)

✗ 취약한 설정
# 루트 MFA 상태 $ aws iam get-account-summary AccountMFAEnabled: 0 → 비밀번호 유출 시 전체 장악
✓ 안전한 설정
# MFA 활성화 $ aws iam enable-mfa-device ... AccountMFAEnabled: 1 → 2차 인증으로 보호

🔧 조치 방법

  1. 루트 계정에 하드웨어/가상 MFA를 등록합니다.
  2. 루트 사용을 최소화하고 일상 작업은 IAM 사용자로 수행합니다.

✅ 점검 체크리스트

  • 루트 계정 MFA가 활성화됨
  • 루트 사용이 최소화됨
