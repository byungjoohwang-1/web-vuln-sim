🔒 계정 잠금 임계값

보안장비 · 계정 관리

위험도: 상
💡 쉽게 말하면
잠금 정책이 없으면 도둑이 열쇠를 무한정 바꿔 끼워볼 수 있습니다. 5번 틀리면 잠그도록 하면, 몇 번 시도하다 막혀서 더는 돌려보지 못합니다.

🎯 직접 해보기 — 공격을 실행해 보세요

아래에서 시스템 상태를 취약 또는 안전(조치 적용)으로 바꾼 뒤 공격 실행을 눌러, 같은 공격이 어떻게 다르게 끝나는지 직접 확인하세요.

현재: 취약한 설정 — 공격이 통할까요?
# 공격자가 잠금 없이 관리 로그인을 무제한 시도한다 # [공격 실행] 버튼을 누르면 시작합니다.

📋 설정 비교 (왜 막혔나?)

✗ 취약한 설정
# 잠금 정책 # show login lockout lockout-threshold: none → 무차별 대입 무제한
✓ 안전한 설정
# 임계값 설정 # set login lockout threshold 5 duration 600 threshold 5 / lock 10m → 5회 실패 시 잠금

🔧 조치 방법

  1. 로그인 실패 임계값(5회 이하)과 잠금 시간을 설정합니다.

✅ 점검 체크리스트

  • 계정 잠금 임계값이 설정됨
  • 잠금 시간이 설정됨
