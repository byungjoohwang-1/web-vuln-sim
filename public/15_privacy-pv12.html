PV-12

⏳ 보유기간 초과 보관

개인정보보호 · 보유·파기

위험도: 상

📋 취약점 개요

보유기간은 법령 기준과 보유 목적에 부합하는 최소한의 기간으로 정해야 합니다. "언젠가 쓸지 모른다"는 이유로 탈퇴 회원 데이터를 남겨두는 것은 위법이며, 유출 사고 시 피해 규모를 결정적으로 키우는 요인입니다.

🖥️ 상태 비교 시뮬레이션

privacy$ (취약)
# 탈퇴 회원 데이터 확인 db$ SELECT count(*) FROM users WHERE status='withdrawn' >> 1,284,552 rows (최장 9년 경과) >> 보유기간 정책: 문서 없음 / 자동 파기 배치 없음 → 유출 시 탈퇴자까지 피해 · 법 제21조 위반

🔧 조치 방법

  1. 개인정보파일별로 보유기간과 근거(법령 또는 동의받은 기간)를 정의해 대장에 등록합니다.
  2. 보유기간 경과 데이터를 자동 탐지·파기하는 배치를 운영하고 실행 결과를 로그로 남깁니다.
  3. 다른 법령에 따라 보존해야 하는 정보는 별도 DB·테이블로 분리해 접근을 제한합니다.
  4. 백업본·로그·개발 환경 사본까지 파기 범위에 포함합니다.

✅ 점검 체크리스트

  • 개인정보파일별 보유기간·근거가 정의됨
  • 보유기간 경과 데이터 자동 파기 운영됨
  • 법정 보존 정보가 분리 보관됨
