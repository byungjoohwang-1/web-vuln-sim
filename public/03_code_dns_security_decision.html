CWE-350: Reliance on Reverse DNS Resolution for Security Decision

KISA 소프트웨어 보안약점 진단가이드(2021) · API 오용
💡 쉽게 말하면
"옆 동네에서 왔다"는 말(DNS 이름)만 믿고 권한을 주면 거짓말(스푸핑)에 속습니다. 인증 토큰으로 신원을 확인해야 합니다.

☕ Java 코드 에디터 취약한 코드
AccessControl.java 💡 역DNS 이름 대신 인증 토큰/검증으로 인가하세요. 
// [취약] 역DNS 이름으로 인가 결정 → DNS 스푸핑으로 우회 가능
String host = request.getRemoteHost();   // 역DNS 조회 결과
if (host.endsWith(".trusted.com")) {
    grantAdmin();
}

🐍 Python 코드 에디터 취약한 코드
access_control.py 💡 역DNS(PTR) 대신 토큰/HMAC 검증으로 신뢰를 판단하세요. 
import socket
# [취약] 역DNS(PTR) 이름으로 신뢰 판단 → 스푸핑 우회 가능
name = socket.gethostbyaddr(client_ip)[0]
if name.endswith(".trusted.com"):
    grant_admin()
