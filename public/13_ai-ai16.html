📋 설정 비교 (왜 막혔나?)

✗ 취약한 설정
# 유튜브 임원 연설 30초로 음성 복제 attacker$ "긴급입니다. 계좌 이체 부탁드려요" (복제 목소리) >> 담당자가 실제 임원으로 착각 → 금액 송금 완료
✓ 안전한 설정
# 콜백 검증 + 이중 승인 policy$ 대표번호 콜백 + 2인 승인 필수 >> 등록된 번호로 확인 — 사기 확인 → 송금 차단

🔧 조치 방법

  1. 전화·음성 지시는 등록된 채널로 콜백 확인하는 절차를 의무화합니다.
  2. 긴급 송금은 2인 승인 등 이중 통제를 적용합니다.
  3. 임원·직원 음성 노출을 인지하고 사내 인증 어구를 둡니다.

✅ 점검 체크리스트

  • 콜백 검증 절차 존재
  • 긴급 송금 이중 승인 적용
