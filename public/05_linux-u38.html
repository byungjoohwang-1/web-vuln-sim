💥 DoS 취약 서비스(echo/discard/daytime/chargen) 비활성화

서비스 관리

위험도: 상
💡 쉽게 말하면
echo/chargen 같은 단순 서비스는 아무 말이나 외치면 똑같이 메아리쳐 주는 확성기와 같습니다. 공격자가 남의 주소를 사칭해 외치면 메아리가 피해자에게 쏟아지죠. 트래픽을 증폭해 마비시키는 데 악용됩니다.

🎯 직접 해보기 — 공격을 실행해 보세요

아래에서 시스템 상태를 취약 또는 안전(조치 적용)으로 바꾼 뒤 공격 실행을 눌러, 같은 공격이 어떻게 다르게 끝나는지 직접 확인하세요.

현재: 취약한 설정 — 공격이 통할까요?
# 공격자가 단순 서비스로 증폭 DoS를 일으킨다 # [공격 실행] 버튼을 누르면 시작합니다.

📋 설정 비교 (왜 막혔나?)

✗ 취약한 설정
# 단순 서비스 활성화 확인 # grep -E "echo|discard|daytime|chargen" /etc/inetd.conf echo stream tcp nowait root internal chargen dgram udp wait root internal → 증폭/반사 DoS에 악용 가능 (취약)
✓ 안전한 설정
# 모두 주석 처리 # grep -E "echo|discard|daytime|chargen" /etc/inetd.conf (출력 없음 또는 모두 #) → 단순 서비스 비활성화 (양호)

🔧 조치 방법

  1. inetd.conf에서 echo/discard/daytime/chargen 라인을 모두 주석 처리합니다.
  2. xinetd 환경에서는 각 서비스를 disable = yes로 설정합니다.
  3. inetd를 재시작하여 적용합니다.

✅ 점검 체크리스트

  • echo/discard/daytime/chargen이 모두 비활성화됨
  • TCP/UDP 양쪽 모두 차단되었는가
