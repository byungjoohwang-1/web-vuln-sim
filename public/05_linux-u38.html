💥 DoS 취약 서비스(echo/discard/daytime/chargen) 비활성화

서비스 관리

위험도: 상

📋 취약점 개요

echo, discard, daytime, chargen 등 단순 서비스는 트래픽 증폭·반사 공격(DoS)에 악용됩니다. 불필요하므로 비활성화해야 합니다.

🖥️ 상태 비교 시뮬레이션

root@server:~# (취약)
# 단순 서비스 활성화 확인 # grep -E "echo|discard|daytime|chargen" /etc/inetd.conf echo stream tcp nowait root internal chargen dgram udp wait root internal → 증폭/반사 DoS에 악용 가능 (취약)

🔧 조치 방법

  1. inetd.conf에서 echo/discard/daytime/chargen 라인을 모두 주석 처리합니다.
  2. xinetd 환경에서는 각 서비스를 disable = yes로 설정합니다.
  3. inetd를 재시작하여 적용합니다.

✅ 점검 체크리스트

  • echo/discard/daytime/chargen이 모두 비활성화됨
  • TCP/UDP 양쪽 모두 차단되었는가
