🔒 /etc/shadow 파일 권한 설정

/etc/shadow 파일 권한 설정

U-18 ⭐ 중요도: 상

📋 취약점 정보

🚨 취약점 개요
/etc/shadow 파일 권한 설정은(는) 시스템 보안을 강화하기 위해 필수적인 설정입니다.

상태 비교

❌
취약한 상태
644 또는 644 이상의 권한
✅
보안 상태
600 권한 (-rw-------)

🖥️ 실습 환경

❌

현재 상태: 취약

$ ls -l /etc/shadow -rw-r--r-- 1 root shadow 5678 /etc/shadow (권한: 644 - 위험)
⚠️ 현재 상태
• 644 또는 644 이상의 권한
• 보안 설정이 미흡한 상태
• 즉시 조치 필요
✅

목표 상태: 보안

$ ls -l /etc/shadow -rw------- 1 root shadow 5678 /etc/shadow (권한: 600 - 안전)
✅ 목표 상태
• 600 권한 (-rw-------)
• 보안 설정이 완벽하게 적용됨
• 정기적 모니터링 필요

⚖️ 수정 전/후 비교

항목 수정 전 (취약) 수정 후 (보안)
