PV-15

🚧 접근통제 미흡 (외부 접속 무제한)

개인정보보호 · 안전성 확보조치

위험도: 상

📋 취약점 개요

개인정보처리시스템은 허용된 IP·경로로만 접근할 수 있게 제한하고, 외부에서 접속할 때는 안전한 인증수단(VPN·전용선·MFA)을 적용해야 합니다. 관리자 페이지가 인터넷에 그대로 열려 있으면 무차별 대입 한 번으로 무너집니다.

🖥️ 상태 비교 시뮬레이션

privacy$ (취약)
# 관리자 페이지 노출 점검 scan$ https://example.com/admin >> 200 OK — 인터넷 전체에서 접근 가능 >> IP 제한 없음 · 2차 인증 없음 · 로그인 실패 제한 없음 → 크리덴셜 스터핑 1회로 전체 회원DB 조회 가능

🔧 조치 방법

  1. 개인정보처리시스템 접근을 허용 IP·네트워크 구간으로 제한합니다.
  2. 외부 접속에는 VPN·전용선 등 안전한 접속수단과 다중 인증(MFA)을 적용합니다.
  3. 일정 횟수 이상 인증 실패 시 계정 잠금·접근 제한 조치를 적용합니다.
  4. 침입차단·침입탐지 기능으로 비인정 접근을 탐지·차단하고 로그를 점검합니다.
  5. 관리용 단말·콘솔은 전용 구간에 두고 인터넷 직접 노출을 금지합니다.

✅ 점검 체크리스트

  • 접근 허용 IP·구간이 제한됨
  • 외부 접속에 MFA/VPN 적용됨
  • 인증 실패 제한·탐지 규칙 운영됨
