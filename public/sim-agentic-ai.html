Exploit a mock tool-using AI agent (ORBIT Assistant): hide commands in untrusted input (indirect prompt injection), give it over-privileged tools, or feed it a poisoned MCP tool. Each risk runs attack → verdict → apply defense → re-check — watch the agent’s trace refuse the same attack once the defense is on.
