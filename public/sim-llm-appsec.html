🧠 LLM 앱·게이트웨이 보안 실습LLM App / Gateway Security Lab OWASP LLM Top 10

모의 LLM 게이트웨이 OrbitLLM Gateway(LLM 프록시·오케스트레이터)에 요청을 직접 던져 인증 우회·명령 주입·SQL 주입·SSRF·프롬프트 템플릿 주입·출력 처리·키 격리·비용·모델 접근제어를 시험합니다. 각 위험은 공격 실행 → 취약/양호 판정 → 방어 적용 → 재점검 순서로, 방어를 켜면 같은 공격이 이번엔 막히는지 확인합니다. Send requests to a mock LLM gateway (OrbitLLM Gateway — an LLM proxy/orchestrator): auth bypass, command injection, SQL injection, SSRF, prompt-template injection, output handling, key isolation, cost, and model access control. Each risk runs attack → verdict → apply defense → re-check — watch the same attack get blocked once the defense is on.

⚡ 이 랩은 실제 악용 중(KEV)인 LLM 게이트웨이 취약점 군을 개념적으로 재구성했습니다: CVE-2026-59822(인증 우회)·CVE-2026-42271(명령 주입)·CVE-2026-42208(SQL 주입) — BerriAI LiteLLM 계열. 특정 제품의 익스플로잇이 아니라, 그 취약점 유형을 안전하게 이해하기 위한 가상 게이트웨이입니다. This lab conceptually reconstructs an actively exploited (KEV) cluster of LLM-gateway flaws: CVE-2026-59822 (auth bypass), CVE-2026-42271 (command injection), CVE-2026-42208 (SQL injection) — BerriAI LiteLLM family. Not a product exploit — a mock gateway to understand the vulnerability classes safely.
교육용 시뮬레이션입니다. OrbitLLM Gateway 는 전부 이 페이지 안의 mock 이며 실제 게이트웨이·모델·서버 접속은 전혀 없습니다. 위험 분류는 공개 기준(OWASP Top 10 for LLM Applications)을 개념적으로 재구성했습니다. 등장하는 키·토큰은 모두 명백한 EXAMPLE 값입니다. Educational simulation. OrbitLLM Gateway is a fully in-page mock — no real gateway, model, or server access. Risk taxonomy follows public guidance (OWASP Top 10 for LLM Applications). All keys and tokens shown are obvious EXAMPLE values.
