🤖 AI 보안 트랙

AI 보안은 완전히 새로운 취약점 목록이 아닙니다. 입력 검증, 인가, 출력 인코딩 같은 익숙한 약점이 모델이라는 새 표면에서 다시 나타나는 쪽에 가깝습니다. 그래서 이 트랙의 카드마다 먼저 보면 좋은 웹 약점을 함께 걸어 두었습니다.

이 트랙의 모든 실습은 페이지 안에서 끝나는 모의 환경입니다. 실제 서비스나 모델을 대상으로 하지 않으며, AI 튜터는 공격 대행, 악성코드 제작, 우회 페이로드 생성 요청을 거부합니다. 개인 API 키 없이 데모 모드로 트랙 전체를 끝낼 수 있습니다.

어디서 시작할까요

💬 AI 튜터 개념을 묻고, 코드 리뷰 힌트를 1단계부터 3단계까지 받습니다. 정답을 먼저 말하지 않습니다. API 키 불필요 🛟 가드레일 연습장 미션 5개. 거부 문장 쓰기, 힌트 설계, 취약 코드 리팩터, 시크릿 탐지, 프롬프트 주입 인지. 규칙 기반 자동 채점 📝 AI 채점기 취약 코드를 직접 고치고 자세한 평가를 받습니다. 개인 키 또는 서버 프록시가 필요합니다. 🧩 AI 생성 코드 랩 생성 도구가 실제로 자주 내놓는 취약 코드 10개를 직접 고칩니다. 어떤 요청이 어떤 코드를 불러왔는지 함께 보여 줍니다. 코드 수정 실습에서 "AI가 만든 코드" 필터
