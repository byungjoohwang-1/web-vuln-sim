ICS-05

🩹 엔지니어링 워크스테이션 노후 OS·미패치

제어시스템(ICS/SCADA) · 시스템

위험도: 상
💡 쉽게 말하면
지원종료된 노후 OS는 부품이 끊긴 낡은 금고입니다. 약점이 공개돼도 고칠 패치가 없죠. 업그레이드하거나, 못 하면 금고를 따로 격리해 지켜야 합니다.

🎯 직접 해보기 — 공격을 실행해 보세요

아래에서 시스템 상태를 취약 또는 안전(조치 적용)으로 바꾼 뒤 공격 실행을 눌러, 같은 공격이 어떻게 다르게 끝나는지 직접 확인하세요.

현재: 취약한 설정 — 공격이 통할까요?
# 엔지니어링 PC의 지원종료 OS 취약점을 공격한다 # [공격 실행] 버튼을 누르면 시작합니다.

📋 설정 비교 (왜 막혔나?)

✗ 취약한 설정
# OS/패치 상태 ews$ winver ; check-patch 지원종료 OS, 최신 보안패치 누락 → 알려진 취약점으로 장악
✓ 안전한 설정
# 패치 또는 보완통제 ews$ apply patches / isolate+whitelist 패치 적용 또는 격리+화이트리스트 → 알려진 공격 차단

🔧 조치 방법

  1. 지원되는 OS로 업그레이드하고 검증 후 보안패치를 정기 적용합니다.
  2. 즉시 패치가 어려우면 망 격리·애플리케이션 화이트리스트로 보완합니다.
  3. 변경 전 백업·시험가동으로 가용성 영향을 검증합니다.

✅ 점검 체크리스트

  • 지원 OS를 사용하거나 보완통제가 적용됨
  • 보안패치가 정기 적용됨
  • 패치 전 백업/검증 절차가 있음
