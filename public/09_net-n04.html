N-04

🔐 비밀번호 암호화(service password-encryption)

네트워크 장비 · 계정 관리

위험도: 상
💡 쉽게 말하면
설정 파일 속 평문 비밀번호는 다이어리에 비밀번호를 적어둔 것과 같습니다 — 그 페이지를 보는 사람은 누구나 알게 됩니다. 설정을 화면 캡처하거나 백업 파일을 입수한 공격자는 비밀번호를 그대로 읽어냅니다.

🎯 직접 해보기 — 공격을 실행해 보세요

아래에서 시스템 상태를 취약 또는 안전(조치 적용)으로 바꾼 뒤 공격 실행을 눌러, 같은 공격이 어떻게 다르게 끝나는지 직접 확인하세요.

현재: 취약한 설정 — 공격이 통할까요?
# 공격자가 설정 파일에서 평문 비밀번호를 읽어낸다 # [공격 실행] 버튼을 누르면 시작합니다.

📋 설정 비교 (왜 막혔나?)

✗ 취약한 설정
! 평문 비밀번호 노출 확인 # show run | include password line vty 0 4 password cisco123 (평문) → 설정 내 평문 노출 (취약)
✓ 안전한 설정
! 암호화 적용 # service password-encryption password 7 0822455D0A16 → 평문 노출 제거 (양호)

🔧 조치 방법

  1. service password-encryption을 적용해 설정 내 평문 비밀번호를 숨깁니다.
  2. 가능하면 단방향 해시(secret)를 우선 사용합니다(type 7은 복호화 가능하므로 보조 수단).

✅ 점검 체크리스트

  • service password-encryption이 적용됨
  • 핵심 비밀번호는 secret(해시)로 설정됨
점검기준: 네트워크 계정 관리 > 비밀번호 암호화
