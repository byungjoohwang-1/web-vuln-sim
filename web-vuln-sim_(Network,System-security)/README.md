# 네트워크 및 시스템 보안 실습 패치

## 이번 구성

- 네트워크 30개, Linux 30개, Windows 30개: 총 90개 설정 실습
- 기존 60개 실습의 문제와 정답·채점 정책·ID 유지, 신규 30개 추가
- 원래 실습 화면과 검색·점수·진도 흐름 유지
- 연관 실습 안에 사건 분석 패널: 설정 자료, 분석 질문, 단계별 힌트, 해설, 용어 사전
- 방화벽·DNS·인증·파일 무결성·Windows 이벤트·백업 모의 데이터 6종
- 검색과 50행 단위 페이지 이동, 전체 로그 CSV 내려받기, 실습별 관찰 노트
- 공식 PDF 묶음과 용량을 표시하던 자료실은 새 패키지에서 제외

## 교육 데이터

192,000개 모의 관측 기록입니다. 정상 대조군과 검토할 사건이 혼재하여 필드 필터링, 세션 연계, 기준선 비교를 연습합니다.
실제 사용자·서버에서 수집한 기록이 아니며 실제 명령이나 네트워크 접속을 실행하지 않습니다.
Windows 자료는 원본 EVTX가 아닌 학습용 정규화 자료입니다. 모든 시각은 UTC입니다.
방화벽 32,000 / DNS 32,000 / 인증 24,000 / 파일 상태 48,000 / Windows 32,000 / 백업 24,000건입니다.
가상 자산은 240대이며 파일 상태는 자산당 200개, 백업 복구 점검은 자산당 100일입니다.
파일 크기를 위한 PDF·이미지·무작위 패딩을 포함하지 않습니다. 데이터의 각 필드는 사건 분석에 쓰이는 시간, 자산, 정책, 세션, 해시, 권한, 복원 상태입니다.

## 사용

1. public/network-system-security.html을 엽니다. Node.js가 있다면 node Preview-NetworkSystemSecurity.cjs로 로컬 서버를 시작할 수 있습니다.
2. 실습을 고르고 기존 방식대로 설정과 퀴즈를 제출합니다.
3. 사건 분석 패널이 있는 문제는 패널을 펼쳐 조건·질문을 읽고 모의 로그 열기를 누릅니다.
4. FW-900처럼 값을 검색하거나 user=ops-review처럼 필드=값으로 좁힙니다.
5. 관찰 노트에 확인 사실·추가 가설·조치 및 검증 계획을 기록합니다.

관찰 노트는 wvs_net_system_notes_v1, 기존 진도는 wvs_net_system_v1에 저장됩니다. 점수·시도 기록은 변경하지 않으며 같은 브라우저·주소에서 유지됩니다.
사건 자료 열기와 노트는 추가 점수를 주지 않습니다. 신규 설정 실습은 기존처럼 설정 100점과 퀴즈 20점입니다.
새 문제 수에 맞춰 전체 대비 완료율은 달라질 수 있습니다. 누적 최고점은 실습별 최고점 합계입니다.
모의 자료는 필요할 때만 불러오므로 최초 화면에서 모든 기록을 로드하지 않습니다.
기존 자료실 주소 network-system-resources.html은 원래 실습 화면으로 연결됩니다.

## 적용

현재 운영 소스에 다음 명령으로 계획을 확인합니다.

    .\Apply-NetworkSystemSecurityPatch.ps1 -ProjectRoot "C:\경로\web-vuln-sim"

반영하려면 다음 명령을 사용합니다.

    .\Apply-NetworkSystemSecurityPatch.ps1 -ProjectRoot "C:\경로\web-vuln-sim" -Apply -OverwriteModule

public 전체를 함께 이식합니다. 설치기는 90개 실습의 검색 색인과 카탈로그를 JSON으로 생성합니다.
기존 플랫폼의 진도 연동·검토·사용자 정의 설정은 보존합니다. 적용 전 기존 파일은 .wvs-patch-backups에 보관합니다.
이전 배포에 남은 PDF를 임의 삭제하지는 않지만 새 화면에서 사용하지 않으며 새 ZIP에 포함하지 않습니다.
정식 주통기 점검 항목과 일대일로 매핑된 진단 도구는 아닙니다. N/L/W는 내부 실습 코드입니다.
운영 사이트 배포는 별도이며 이 작업에서 수행하지 않습니다.

## 검증 상태

이 90개 실습 확장본에는 테스트를 실행하지 않았습니다. 이전 60개 실습의 검증 보고서를 이 버전의 검증 결과로 포함하지 않습니다.
